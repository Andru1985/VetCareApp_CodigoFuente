VetCare App

Sistema móvil de agendamiento veterinario y gestión de servicios médicos para mascotas

Aplicación Android desarrollada como proyecto académico en el Politécnico Grancolombiano. Permite a los propietarios de mascotas gestionar sus datos y citas veterinarias desde el celular.

Descripción

VetCare App facilita la comunicación entre propietarios de mascotas y médicos veterinarios. La aplicación centraliza el registro de usuarios, la información de las mascotas y el agendamiento de citas en una interfaz sencilla.

Funcionalidades
Registro e inicio de sesión de usuarios
Gestión del perfil del propietario
Registro y consulta de mascotas
Agendamiento de citas veterinarias
Menú lateral con las secciones: Perfil, Fotos, Video, Web y Botones
Almacenamiento local de datos con SQLite
Arquitectura de la interfaz

La pantalla principal usa dos fragmentos:

Fragmento izquierdo: menú de navegación con las opciones de la app.
Fragmento derecho: contenido dinámico que cambia según la opción seleccionada.
Actores
Propietario de mascota
Médico veterinario
